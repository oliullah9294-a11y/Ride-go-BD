# Ride Go BD — MVP Prototype

এটি Ride Go BD-এর প্রথম clickable UI prototype।

## যেগুলো ডেমো করা হয়েছে
- Ride Go BD branding
- Mobile + OTP flow
- Driver / Passenger role
- Passenger: গাড়ি খোঁজা
- Driver: যাত্রী খোঁজা
- Fare negotiation
- Driver + Passenger service fee
- Payment success demo
- Live journey screen
- Distance / time display
- Close Trip → নতুন করে খোঁজা

## গুরুত্বপূর্ণ
এটি এখনো production app নয়। Real app করতে পরের ধাপে যুক্ত করতে হবে:
1. Firebase/Auth + real OTP
2. Real database/backend
3. Google Maps API + GPS/live location
4. bKash merchant/payment gateway
5. Server-side payment verification
6. Push notifications
7. Real-time trip matching
8. Admin panel
9. Security rules
10. Android APK/AAB build and Play Store setup

## চালানোর নিয়ম
index.html ফাইল ব্রাউজারে খুললেই prototype দেখা যাবে।
